## `/git-btw` 
Usage: 

    /git-btw <guidance for the side task, may reference code in the current dirty tree>

By-the-way chore edits, fix-ups and little improvements separate from current work-in-progress.
Runs in an isolated worktree on a fresh cut from the default branch (main/master), creates a draft PR/MR via gh or glab. Your current work stays untouched
